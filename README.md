# Find Your Pace · 拉片分析

面向 AIGC 制作的图文拉片：节奏与呼吸感、故事结构、人物真实感、色彩与构图、视听关系、社会共鸣，以及对应的生成与后期方法。

分析对象为 FilmLaab 2024 年为 On 自主创作的 Spec Ad。

## 给 AI 使用

先输入完整 Markdown；需要分析具体构图时，再附对应的参考帧或原片。Markdown 中出现图片链接，不代表模型已经读取图片像素。需要精确剪辑信息时，另行提供原视频并逐帧核验。

## 核验边界

这是依据画面预览帧、部分暂停画面、英文自动字幕和制作方自述完成的视觉与叙事分析。**未直接试听音轨**，原曲、曲风、配器、BPM 和精确卡点仍待核验；音乐部分给出的是建议方案。参考节点不等于完整分镜 EDL，约 2 秒采样可能漏掉短镜头。
